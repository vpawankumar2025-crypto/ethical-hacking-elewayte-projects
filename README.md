# Ethical Hacking Projects — Elewayte Externship

Penetration testing reports completed as part of the Elewayte Cyber Security 
externship (June–July 2026), by Pawan Kumar V.

## Contents

- **Major Project** — Full black-box penetration test of *Mission Pumpkin v1.0 
  (PumpkinFestival)*, a VulnHub VM. Covers reconnaissance through privilege 
  escalation and root access, with 10 documented findings, screenshots, 
  vulnerabilities identified, and remediation recommendations.

- **Minor Project** — Web application penetration test of `testphp.vulnweb.com` 
  (Acunetix's authorized test site). Covers 5 findings including SQL injection 
  (UNION-based and authentication bypass), reflected and stored XSS, and an 
  open redirect, each with proof-of-concept steps and remediation guidance.

All testing was performed against intentionally vulnerable, authorized targets 
for educational purposes only.
